    memory

    memory: Memory

    The shared memory every worker runs on. It must be a shared memory with a declared maximum that leaves room for one private stack per worker. The pool grows it by that much at open.

    • Defined in src/slices.ts:16

    Optionalownership

    ownership?: OwnershipPlan

    The plan of a module that redirectOwnership rewrote. Each worker gets a private copy of every window next to its stack, the owner copies the last record's bytes back after a clean run, and a trap in any slice restores writes and runs the calls serially in place.

    OptionalstackBytes

    stackBytes?: number

    Bytes of private stack per worker, a multiple of 65,536. Only a module that keeps a stack pointer global gets stacks. The default is 65,536.
