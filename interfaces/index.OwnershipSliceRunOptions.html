    Optionalaudit

    audit?: boolean

    Runs the same slices serially on a copy of the memory taken before the run and compares the result and every byte below the stacks. A difference throws SliceConflictError. It costs a serial execution and a memory copy, and is meant for tests and canaries.

    writes: [number, number][]
