    Class PageDirectory

    Volatile manifest coordinator. Publication is atomic within this instance. Recovery requires a persisted manifest and decision log; this constructor only creates a fresh zero-filled arena. Exactly one trusted directory may issue fences for its scope. Restart with a new incarnation; reusing an old scope is unsupported and can collide with old versions and delayed requests.
