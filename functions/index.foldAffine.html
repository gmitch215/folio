    • foldAffine(

          model: AffineModel,

      Folds input through the kernel on pool workers started with serveAffine, and returns the state the serial call over the same bytes returns.

      exact: pass 1 runs every chunk but the last from state zero (the first from initial); the model turns the offsets into each chunk's predicted start; pass 2 runs chunks 1 to n-1 from their predicted starts; an ordered check compares each chunk's real end state with the next chunk's predicted start. If all agree, the final state is the serial one by induction, whatever the model got wrong. At the first disagreement the rest of the input runs serially from the last real state. This equals the serial call when the kernel composes over a split (T(s, x||y) = T(T(s, x), y)), which the probe checks on samples and nothing here proves.

      audit: one pass from state zero, the model combines the offsets, and audit chunks run again from their predicted starts. A disagreement reruns the whole input serially. A chunk that is not sampled is trusted: the model's error in it goes undetected.
