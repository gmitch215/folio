# Original Module

Registers the unmodified PHP module, 16/64/128 MiB own-memory controls and one memory importer.
Prepare from the repository root with `node experiments/bootimage/prepare.ts`, then run
`node experiments/bootimage/local.ts original`. Deployment uses `wrangler.original.jsonc`.
The [method](../../METHOD.md) defines checksums and bounds. Historical variant tag: `a`.
